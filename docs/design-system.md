# Дизайн-система

## Направление

Весь интерфейс dark-first. Светлая тема не проектируется как равноправная тема на старте.

Ориентир: минималистичные AI-интерфейсы уровня Codex app, ChatGPT, Claude и современных agent workspace продуктов.

## Принципы

- темный фон без тяжелой декоративности;
- мягкие границы `rgba(255,255,255,0.07-0.12)`;
- поверхности с малой прозрачностью;
- плавные transition `duration-300`;
- крупные интерактивные зоны на мобильных экранах;
- адаптивность от 320px до широких desktop-мониторов;
- отсутствие маркетингового hero внутри закрытого приложения.

## Токены

Основные цвета заданы в `src/index.css` через Tailwind v4 `@theme`.

- `night`: основной фон;
- `graphite`: панели;
- `ice`: основной текст;
- `mint`: акцент и состояния безопасности;
- `violet`: дополнительный акцент для будущих состояний.

## Компонентные правила

- Карточки используются только для осмысленных панелей, не для каждой секции.
- Кнопки и поля имеют стабильную высоту, чтобы интерфейс не прыгал.
- Иконки берутся из `lucide-react`.
- Любая новая крупная зона должна иметь mobile-first поведение.
