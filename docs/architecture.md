# Архитектура

## Базовый выбор

Seira стартует как client-only SPA на React + Vite. SSR намеренно не используется на первом этапе, потому что почти весь продукт закрыт авторизацией, а публичный SEO-контур пока не является ключевой задачей.

## Frontend

- React 19
- Vite 8
- TypeScript 6
- TanStack Router для типобезопасной навигации
- TanStack Query для серверного состояния
- Tailwind CSS 4 для dark-first UI

## Backend

Базовый backend: Supabase.

- Supabase Auth отвечает за identity и сессии.
- Postgres хранит пользовательские данные, память, диалоги и настройки.
- RLS является основным механизмом авторизации данных.
- Edge Functions или отдельный API выполняют действия, которым нужны секреты: вызовы моделей, внешние интеграции, фоновые операции.

## Граница безопасности

В браузере допустимы только publishable/anon ключ Supabase, пользовательская сессия и UI-состояние. Service role ключи, ключи моделей и внешних API всегда остаются на серверной стороне.
